# tmvp docs site

Astro + Starlight. Content under `src/content/docs/`:

- hand-written: `index.mdx` (splash), `start/`, `concepts/{systems-and-types,via-chains,audit-log}.md`, `agent-skills/{discoverer,product-skill}.md`, `security/`, `404.md`
- generated by `scripts/sync-docs.mjs` (runs before `dev` and `build`): every `docs/llms/*.md` topic, one page per `docs/llms/types/*.md`, the discoverer steps and question bank, and `reference/commands.md` from `tmvp help` / `<cmd> --help` / `tmvp verbs`. Edit the sources in the repo, not the generated files.

```sh
bun install
bun run dev        # sync + astro dev
bun run build      # sync + static site in dist/
TMVP_BIN=../bin/tmvp bun run build   # use a built binary instead of `go run` for the command reference
SITE=https://muthuishere.github.io BASE=/tmvp bun run build   # when hosted under a sub-path
```

Theme: `src/styles/theme.css` (charcoal + one amber accent, Geist / Geist Mono, sharp ruled panels, `[NN]` eyebrows; motion off under prefers-reduced-motion). Splash hero: `src/components/Hero.astro` + `home/HeroScene.astro` (the glasses over a canvas scene); home sections: `src/components/home/`. Logo: `src/assets/logo-{light,dark}.svg` and `public/favicon.svg`: the portal (an environment's amber ring) with the glasses inside it. The header also shows the released version (latest git tag, read at build time) linking to the changelog page.

Note: internal links are root-absolute (`/start/install/`); hosting under a sub-path (BASE) needs them prefixed.
